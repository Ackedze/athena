# Публикация каталогов в GitHub репозиторий

## Обзор

Athena умеет публиковать в GitHub не только component catalogs, но и JSON токенов и стилей. Все файлы отправляются в репозиторий `ackedze/design-system_ab` в директорию `catalogs/`.

## Как использовать

### 1. Подготовка GitHub токена

Для публикации каталогов вам потребуется GitHub Personal Access Token:

1. Перейдите на https://github.com/settings/tokens
2. Нажмите "Generate new token"
3. Выберите scope `repo` (полный доступ к репозиториям)
4. Скопируйте полученный токен

### 2. Сбор и публикация

1. В Athena откройте нужную вкладку: `Components`, `Tokens` или `Styles`.
2. Соберите данные на активной вкладке.
3. Нажмите кнопку `Опубликовать` в правой верхней части окна.
4. При первой публикации в текущей сессии появится окно для ввода GitHub token.
5. После сохранения токен будет использоваться повторно до закрытия окна плагина.
6. JSON будет опубликован под тем же именем, что и локально скачиваемый файл.
7. Путь в репозитории: `catalogs/{file-name}.json`.

### 3. Где найти опубликованный каталог

После успешной публикации, файл появится в:

```
https://github.com/ackedze/design-system_ab/blob/main/catalogs/{catalog-name}.json
```

## Структура файлов в репозитории

Опубликованные каталоги хранятся в директории `catalogs/` репозитория:

```
design-system_ab/
  catalogs/
    my-design-catalog.json
    another-catalog.json
    ...
```

## Имена файлов

Имя публикации всегда совпадает с именем скачиваемого файла.

Правила:

- компоненты: `library -- page-name`
- токены: `library -- tokens`
- стили: `library -- styles`

## Безопасность

- GitHub token хранится только в памяти текущей UI-сессии плагина
- Токен отправляется только при публикации каталога
- Рекомендуется использовать токены с ограниченными правами доступа

## Обновление существующего каталога

Если файл с таким же именем уже опубликован, он будет обновлён. История изменений сохраняется в Git.

## Возможные проблемы

### "GitHub token не найден"

- Убедитесь, что ввели токен в диалоге
- Если плагин был закрыт, токен нужно ввести снова
- Попробуйте ещё раз: нажмите `Опубликовать` и введите токен

### Ошибка "401 Unauthorized"

- Проверьте, что токен введен правильно
- Убедитесь, что у токена есть scope `repo`
- Проверьте срок действия токена

### Ошибка "403 Forbidden"

- У используемого токена нет доступа к репозиторию
- Убедитесь, что токен имеет scope `repo`

### Ошибка "CORS error"

- Это не должно происходить для Figma плагинов
- Если произойдет, обновите плагин до последней версии
